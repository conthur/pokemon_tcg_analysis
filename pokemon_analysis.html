Binary and Categorical Data

A good majority of the data we have collected is either categorical or binary. Here are a couple of ways in which to explore these data types

Mode

What is the most common category in these columns

get_mode = function(v, na.rm = TRUE) {
  
  # Remove NAs
  v_clean <- v[!is.na(v)]
  
  if (length(v_clean) == 0) {
    return(NA)
  }
  
  uniqv <- unique(v_clean)
  uniqv[which.max(tabulate(match(v_clean, uniqv)))]
}
