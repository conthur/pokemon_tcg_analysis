# Pokemon TCG Analysis Repository

What factors are important in determining a Pokémon card's price?

## Purpose

This repository details the workflow in which the problem above is presented and then a dataset is made in order to explore the relationships between a Pokémon card's attributes and it's market price.

### Workflow

+ **pokemon_data_engineering.qmd**: This file includes the code which actively queries the official Pokémon TCG API and builds a dataset for anaylsis purposes.

+ **pokemon_eda.qmd**: This file includes the exploratory data analysis techniques used to explore and understand the data.
